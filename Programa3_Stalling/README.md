
# Programa 3 — Stalling

Proyecto 2 — Arquitectura de Computadoras

## Objetivo

Verificar el mecanismo de stalling del procesador
RISC-V RV32I Pipeline de cinco etapas, especialmente
ante una dependencia Load-Use.

## Archivos

- stalling.asm: Programa Assembly de prueba.
- stalling.mem: Instrucciones en hexadecimal.
- tb_stalling.v: Testbench de verificación.

## Señales que se verificarán

- StallF
- StallD
- FlushE
- ResultSrcE
